# 곱셈 놀이터

이 저장소는 학생용 곱셈 메모리 카드 게임과 전자칠판용 스피드 게임 배포용입니다.

## 배포
`index.html`을 저장소 최상위에 올리고 Settings → Pages → Deploy from a branch → main / (root)로 설정합니다.

학생 기록을 저장하려면 Google 스프레드시트의 Apps Script 웹 앱을 별도로 설정하고 `index.html`의 `RECORD_ENDPOINT`를 연결해야 합니다. 연결 전에는 기록이 교사에게 저장되지 않습니다.

학생의 이름은 입력하지 않고 학년·반·번호만 수집합니다. 결과는 수업 참여 확인용으로만 사용하세요.
